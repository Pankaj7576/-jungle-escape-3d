# Jungle Escape 3D — The Lost Temple

An original, mobile-friendly 3D endless runner set in an Indian jungle and ancient-temple adventure. The game is designed for portrait Android screens and modern desktop browsers.

## Play
Open `index.html` through GitHub Pages or another static web host. The game loads Three.js 0.160.0 from jsDelivr, so an internet connection is required.

## Controls
- Swipe left/right to change lanes.
- Swipe up to jump and down to slide.
- Use the on-screen buttons on touch devices.
- Desktop: Arrow keys or WASD; Space to jump; Escape to pause.

## Current gameplay
- Three-lane endless running with increasing speed and difficulty.
- Jumping, sliding, lane switching and obstacle avoidance.
- Coins, keys, diamonds, treasure chests and a locked secret-vault encounter.
- Shield, coin magnet and speed-boost power-ups.
- Guardian chase, pause/restart flow, settings and locally saved best score/coin bank.
- Procedural jungle, temple, road, vegetation and character visuals.
- Synthesized sound effects and optional simple background tone.

## Performance
Low/Medium/High graphics settings adjust rendering quality and shadows. Actual frame rate depends on the Android device, browser and GPU.

## Honest project status
- Characters and environment are procedural meshes with code-driven movement; imported high-detail GLB rigs and motion-captured animation are not included yet.
- No third-party model, texture, image, music or recorded sound files are bundled.
- The game has passed a JavaScript module syntax check, but has not yet been device-tested across Android models.
- WebGL and network access to the Three.js CDN are required.
