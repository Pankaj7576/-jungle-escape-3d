# ASSET_CREDITS.md

## Procedural original assets
The following are generated directly by this project's JavaScript at runtime and are not downloaded third-party assets: Indian-inspired stone shrine facades and stepped shikhara silhouettes, jungle trees, ruins, torches, statues, bridges, waterfall sheets, treasure hunter character, jungle guardian, coins, keys, diamonds, treasure chests, vault entrance, power-up symbols, track, obstacles and synthesized sound effects.

No Temple Run artwork, characters, logos, maps, audio, or other proprietary assets are used. The architecture is a broad fictional adventure-game interpretation and does not reproduce a specific protected monument or sacred icon.
