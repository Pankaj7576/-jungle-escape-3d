## Original project assets
The player, guardian, temple structures, trees, obstacles, coins, props, procedural textures, user interface and synthesized audio are generated by the project's JavaScript code at runtime.

No third-party model, texture, image, music or recorded sound-effect files are bundled in the current revision.

## Future asset additions
Any future GLB model, PBR texture, image, music or sound asset must be checked individually for its license and attribution requirements before being added. Record the source, creator, license and any required attribution here.

## Visual-quality note
The current project uses procedural geometry and code-driven character motion. It does not yet include photorealistic imported character rigs, motion-captured animation, scanned temple assets or recorded environmental audio.
