# Asset credits and licensing

## Bundled third-party assets

None. No external GLB, texture, font, image, or audio file is currently bundled. The temple, trees, props, hero fallback, guardian fallback, obstacles, and small PBR-like stone/soil/bark/moss textures are generated by original project code. Sound effects are synthesized with Web Audio.

## Verified CC0 sources researched on 2026-11-09 — candidates only, not bundled

- **Innerscene — Locomotion collection - Sam 3D Person, Animated**: https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-sam-3d-person-animated-dc23800f. The source page identifies the GLB as CC0/public domain and describes a skinned adult male with seven looping locomotion clips. Listed source file size: 20.9 MB. This is a technical candidate, not the final Indian adventurer design. Source page: https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-sam-3d-person-animated-dc23800f
- **Grab3D — Werewolf**: https://grab3d.com/models/creatures/werewolf/. The source page identifies the asset as CC0 1.0 and lists a separate rigged GLB export with walk/run clips (listed as 14 MB). A separate lightweight tier is described as 400k triangles/1K textures; verify the selected rigged export with the inspector. This is a technical candidate, not the final Indian mythic guardian.
- **ambientCG — Rock 024**: https://ambientcg.com/view?id=Rock024. The official asset page states all ambientCG assets are CC0 and lists a 1K JPG archive. Not downloaded or bundled.
- **Quaternius — Universal Animation Library**: https://quaternius.com/packs/universalanimationlibrary.html. The source page identifies the animation pack as CC0 and lists 120+ humanoid animations in glTF/GLB-capable export formats. Not downloaded or bundled.
- **Poly Haven**: https://polyhaven.com/license. Poly Haven states its asset library is CC0. No specific temple model was selected or bundled in this milestone.

## Important distinction

A source being CC0 does not mean its file is already included in this ZIP. Only assets listed under “Bundled third-party assets” have been downloaded and integrated. Keep the exact source page and license evidence with every future addition. Do not use assets whose license cannot be verified.
