## Procedural assets

The bridge geometry, stone parapets, canyon/mountain/cloud scenery, obstacles, coin/power-up meshes, guardian geometry, and fallback character/guardian animation are generated by project source code. They are not imported third-party model files.

## Runtime dependencies

Three.js, Vite, and Capacitor are declared in `package.json`. Their package licenses should be preserved from their respective package distributions when preparing a formal third-party notices bundle.

## Audit rule

Do not infer a license from a filename, model appearance, or the fact that a file is already in Git. Record the creator, original URL, exact license name/version, and any attribution text only after checking the original asset page or a license file supplied with the asset.
